# HeptaBao

HeptaBao is an independent Rust reimplementation program for an OpenBao-compatible secrets-management server.

The repository is currently in `PLANNING_ONLY / NO_COMPATIBILITY_CLAIM / NOT_PRODUCTION_AUTHORITY` state. All compatibility, migration, production, release, mixed-cluster, and physical OpenBao storage authority is fail-closed until signed qualification evidence explicitly grants a bounded authority.

The executable Plan V1.1 and the first H00 governance implementation package are being prepared on a dedicated development branch.
